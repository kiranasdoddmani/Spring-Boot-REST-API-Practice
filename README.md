# Spring Boot REST API Practice

## About the Project

This project focuses on learning the fundamentals of REST API development using Spring Boot. It demonstrates how to handle HTTP requests, receive client data, extract URL parameters, and return responses with appropriate HTTP status codes.

## Concepts Covered

- REST API Development using Spring Boot
- GET and POST HTTP methods
- Path Variables
- Request Parameters
- Request Body
- ResponseEntity
- HTTP Status Codes
- Client-Server Communication
- API Testing using Postman

## Technologies Used

- Java
- Spring Boot
- Spring Web
- Maven
- Postman

## Features

- Retrieve student details
- Access student information using an ID
- Search students using request parameters
- Receive student data from the client
- Return appropriate response messages
- Handle valid and invalid student IDs
- Manage HTTP response status codes

## API Testing

All API endpoints are tested using Postman to understand how clients send requests and receive responses from a Spring Boot application.

## Learning Objectives

- Understand REST API fundamentals.
- Learn how Spring Boot handles HTTP requests.
- Understand how JSON data is converted into Java objects.
- Learn to extract values from URL paths and query parameters.
- Understand response handling using ResponseEntity and HTTP status codes.
